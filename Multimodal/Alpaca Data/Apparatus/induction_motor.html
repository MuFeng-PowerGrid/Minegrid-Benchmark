Induction Motor

Stator and rotor fluxes, rotor motion, load torque, and optional protection dynamics.

Model scope

Stator/rotor fluxes and mechanical speed form the electromechanical core. The engineering configuration adds applied load torque, squared-voltage measurement, a thermal indicator, and an undervoltage timer. Protection gating follows the equations; a protection state does not itself represent an external network circuit breaker.

Detailed entry: Detailed engineering configuration. Alternative control configurations retain their own state and equation sets.

induction_motor_engineeringinduction_motor
Continuous-time convention: dx/dt = f(x,z,u;p), 0 = g(x,z,u;p), and y = h(x,z,u;p). Time is in seconds. Differential equations below show the actual derivatives. Terminal voltage is a network boundary input. See model conventions for symbols, bases, reference frames, and limiter definitions.
