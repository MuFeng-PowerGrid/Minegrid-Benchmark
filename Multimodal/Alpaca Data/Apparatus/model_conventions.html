Model Conventions

Mathematical notation, physical boundaries, and nonlinear logic

Continuous-time representation

dx/dt = f(x, z, u; p)
0 = g(x, z, u; p)
y = h(x, z, u; p)

x denotes dynamic states, z implicit algebraic unknowns, u external inputs and references, p parameters, and y outputs. Time is measured in seconds. An explicit intermediate quantity has no independent dynamic memory. In a pure ODE configuration, z is empty.

The differential-equation tables display actual time derivatives. Every implicit algebraic row is a residual equal to zero. Explicit algebraic tables define the remaining intermediate quantities and outputs. All symbols retain the same names across the tables. The suffix _dev identifies the device instance.

The notation ** denotes exponentiation; sqrt is the principal square root; Abs is absolute value; and Min/Max are minimum/maximum. Piecewise evaluates its cases in order and selects the first true condition.

Units, bases, and reference frames

Models may combine SI and per-unit quantities. Units are defined by each port's unit, frame, base, and sign entries and by the equations. The dq suffix alone does not specify a unit. model_native denotes the component's original normalization. Integral-state scaling depends on the derivative and whether the integral gain is included in the state definition.

Network dq and device dq frames are distinct. PLL angle, grid-forming angle, or rotor angle determines the transformation. The documented signs, power factors, and line-to-phase conversions are part of each model. Voltage, current, and power bases must be interpreted together with these transformations.

Port signs define the positive direction. Device current injection and internal absorbed power may use different conventions, especially for loads. The equations and port contracts identify the required direction in each case.

Device boundary and configuration

Terminal network voltage is an external boundary variable. A connected network contributes its own electrical constraints and Kirchhoff current equations. Reference values in the parameter tables describe the documented model configuration.

Distinct control modes have distinct state and equation sets. Structural options that introduce or remove dynamic blocks belong to the complete configuration in which they are listed. The PQ, EQ, PU, and EU modes denote active power/reactive power, DC voltage/reactive power, active power/AC voltage, and DC voltage/AC voltage, respectively.

For sequence-control extensions, the sequence-reference angle evolves as theta_sequence(t) = theta_sequence(0) + omega_b t. The base angular frequency follows the device frequency base. A pn0 configuration contains only the sequence states and ports explicitly listed; the name does not imply an independent zero-sequence state in every configuration.

Limits and logical flags

clip(a, l, h) = min(max(a, l), h)

A limiter uses mutually exclusive in-range, lower-limit, and upper-limit flags. With comparison tolerance ε = 10⁻⁹, the lower flag is active when a < l − ε, the upper flag is active when a > h + ε, and the in-range flag is active otherwise. A disabled limiter, or one with both bounds disabled, has f_in = 1 and f_lo = f_hi = 0. no_lower and no_upper disable their respective comparisons.

A deadband uses the same comparison flags, but its output is defined by its own equation. Its output is not necessarily the clipped input.

For an anti_windup_limiter, the additional high-side flag is active when f_hi = 1 and the specified derivative component xd exceeds 10⁻¹². The low-side flag is active when f_lo = 1 and xd is below −10⁻¹². Anti-windup may also enter a derivative directly as back-calculation feedback. The relevant derivative and block properties define its exact action.

A cmp_low block is active when its input is below its threshold; strict = false includes equality. For a rate_limit block, f_rlo is active when ud ≤ rate_lower + 10⁻⁹, and f_rhi is active when ud ≥ rate_upper − 10⁻⁹. Both rate flags are zero when the block is disabled.

Limits embedded directly as Min, Max, Abs, or Piecewise remain part of the nonlinear equations even if no separate logical block is listed. The 25-state synchronous-generator model uses safe_time(T,ε) = T when |T| > ε and ε otherwise.
